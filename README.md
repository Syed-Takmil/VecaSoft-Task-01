# Order Tracking Screen — Assessment

A modern, mobile-first e-commerce Order Tracking screen built with React and Tailwind CSS. The interface handles standard in-transit tracking as well as three critical edge-case scenarios with custom modal dialogs.

## Features
- **Visual Delivery Timeline:** Clean progress stepper with current status indicators.
- **Scenario State Switcher:** Evaluator control bar to easily toggle between:
  1. Standard In-Transit
  2. Delayed Order (extended timeline alert)
  3. Delivered but Not Received (missing package reporting modal)
  4. Tracking Not Available Yet (processing state)
- **Interactive Modals:** Custom React modals for live chat, phone support, and ticket submission.
- **Mobile Responsive:** Designed specifically for 360px–430px mobile viewports.

---

## Tech Stack
- **Framework:** Next.js
- **Styling:** Tailwind CSS
- **Icons:** Lucide React (`lucide-react`)
